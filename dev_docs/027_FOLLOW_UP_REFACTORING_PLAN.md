# План рефакторинга страницы «Авто-дожим и сценарии» (Kvik.ai)

> **Статус:** 📋 Проект редизайна и упрощения интерфейса  
> **Цель:** Снизить когнитивную нагрузку, убрать визуальный шум, избавить интерфейс от технического англоязычного жаргона и выстроить логику вокруг естественного пути клиента (Customer Journey).  
> **Целевая аудитория:** Владельцы малого и среднего бизнеса (салоны красоты, барбершопы, клиники, студии), администраторы и управляющие, которым важна простота и понятный результат без сложных настроек.

---

## 1. Главные проблемы текущего экрана (Анализ по скриншотам)

### 1.1. Двойные контролы и баннеры-дубликаты (Скриншот 1)
* **Проблема:** В шапке страницы уже есть статус `[Включено]`, а сразу под ней расположен огромный серый блок на всю ширину: *«Автоматизации активны — ИИ вовремя напоминает о записях...»* с еще одним переключателем.
* **Результат:** Пустая потеря ~90px полезного пространства экрана и визуальный повтор.

### 1.2. Англицизмы и технический жаргон
* В интерфейсе для русскоязычного бизнеса присутствуют термины, понятные только разработчикам:
  * `Lead Abandonment` в заголовке главной карточки;
  * `Step 1 (+2h)`, `Step 2 (+20h)`, `Step 3 (+48h)` на графиках аналитики;
  * `WhatsApp HSM-шаблон`, `1-Click`, `Win-Back`;
  * `BullMQ Follow-Up Engine`, `Правило ≥ 48ч`.
* **Результат:** Страх пользователя нажать что-то не то из-за ощущения «сложной технической системы».

### 1.3. Нарушение правила вложенности и визуальный перегруз
* Внутри карточки «Сценарий дожима лидов»:
  * 3 огромных шага, у каждого свой фиолетовый бейдж, заголовок, время в скобках, развернутое описание, иконка часов и выпадающий список;
  * Четвертый вложенный серый блок «Авто-закрытие сделки через 72 часа» с иконкой щита;
  * Огромные фиолетовые и серые информационные плашки («Анти-спам защита KVIK: Если клиент записался за 25 часов...», «Если срок дожима наступает ночью...»).
* **Результат:** Глаз не знает, куда смотреть; карточки перегружены рамками внутри рамок.

### 1.4. Смешение разрозненных сценариев в одну карточку
* Карточка «Сбор отзывов в 2GIS и повторные визиты» объединяет два принципиально разных триггера:
  * Запрос отзыва (отправляется через **2 часа** после визита);
  * Повторный визит (отправляется через **30 дней** клиенту, который давно не стригся/не был на процедуре).
* **Результат:** Нелогичная ментальная модель.

### 1.5. Перегруженная аналитика (Скриншот 3)
* Прогресс-бары шагов дожима заполнены однообразным толстым фиолетовым цветом, текст `Отправлено: 0  Ответов: 0 (45%)  0 записей (0.0%)` слит в одну нечитаемую строку.
* Непонятна воронка: сколько клиентов отсеялось на каждом этапе.

## 2. Ключевые изменения и концепция рефакторинга

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                        Единый путь клиента (Жизненный цикл)                 │
├──────────────────────┬──────────────────────┬───────────────────────────────┤
│ 1. До записи         │ 2. Перед визитом     │ 3. После визита               │
│ (Клиент замолчал)    │ (Клиент записан)     │ (Клиент завершил визит)       │
│                      │                      │                               │
│ • 1-е касание (+2 ч) │ • За 24ч до записи   │ • Отзыв в 2GIS (+2 ч)         │
│ • 2-е касание (+20 ч)│ • За 2ч до записи    │ • Повторный визит (+30 дней)  │
│ • Финал (+48 ч)      │                      │                               │
│ • Архив лида (72 ч)  │                      │                               │
└──────────────────────┴──────────────────────┴───────────────────────────────┘
                                       │
                         4. Правила тишины (Ночной режим)
```

### 2.1. Убираем лишнее (Decluttering):
1. **Удалить большой верхний баннер-активатор.** Статус активности и главный переключатель перенести в компактный заголовок страницы.
2. **Убрать все английские термины.** Полная русификация без калек:
   * `Lead Abandonment` $\rightarrow$ **«Возврат замолчавших клиентов»**
   * `Step 1, Step 2, Step 3` $\rightarrow$ **«1-е касание», «2-е касание», «3-е касание»**
   * `Win-Back` $\rightarrow$ **«Приглашение на повторный визит»**
   * `1-Click` $\rightarrow$ **Убрать бейдж** (это само собой разумеющееся действие)
   * `WhatsApp HSM-шаблон` $\rightarrow$ **«Шаблонное уведомление»**
3. **Убрать длинные блоки технических объяснений.**
   * Описание анти-спама спрятать в компактную всплывающую подсказку `(?)` или лаконичный подстрочник в 1 строку.
   * Описание переноса ночных сообщений на 09:15 сделать аккуратной подписью под полями времени, без отдельной серой рамки.
4. **Снять визуальную тяжесть шагов:**
   * Сделать линейную аккуратную таймлайн-цепочку вместо трех тяжелых вложенных карточек.
   * Каждое касание — это компактная строка: `[№] Название касания · Задержка (выбор) · Вкл/Выкл`.

## 3. Детальный план рефакторинга компонентов

### ЭКРАН 1: «Сценарии и правила»

#### Компонент 1: Шапка и единый переключатель (`AutomationsHeader`)
* **Было:** Заголовок + Бейдж «Включено» + Кнопка «Тестовый запуск ИИ» + Ниже огромный баннер со вторым тумблером.
* **Станет:**
  * Заголовок: **Авто-дожим и напоминания**
  * Подзаголовок: *«Умные касания для возврата клиентов, напоминания о визитах и сбор отзывов»*
  * Справа в шапке: аккуратный переключатель мастер-режима (`Активно / На паузе`) + кнопка «Проверить работу ИИ».
  * **Баннер-дубликат удаляется полностью.**

#### Компонент 2: Сценарий «Возврат замолчавших клиентов» (`AbandonmentSequenceCard`)
* **Концепция:** Таймлайн-цепочка из 3 шагов без вложенных серых рамок.
* **Шаг 1 — Мягкое напоминание:**
  * *Текст:* «Вежливый вопрос по услуге или помощь с выбором времени»
  * *Тайминг:* Выпадающий список (1 ч / **2 ч** / 3 ч)
* **Шаг 2 — Предложение свободных окон:**
  * *Текст:* «Напоминание о доступном времени до истечения суток»
  * *Тайминг:* Выпадающий список (16 ч / **20 ч** / 22 ч)
* **Шаг 3 — Завершающее предложение:**
  * *Текст:* «Финальное сообщение или спецпредложение»
  * *Тайминг:* Выпадающий список (36 ч / **48 ч** / 72 ч)
* **Завершение:** Строка внизу карточки: *«Если клиент не ответил в течение 72 часов: завершить сделку как „Не ответил“»*.

#### Компонент 3: «Напоминания о предстоящем визите» (`VisitRemindersCard`)
* Компактные переключатели:
  1. **За 24 часа до визита:** «Запрос подтверждения (Приду / Перенести)». Рядом подсказка `(?)` об автоматическом пропуске, если запись создана менее чем за 24 ч.
  2. **За 2 часа до визита:** «Короткое напоминание перед выездом с адресом и временем».

#### Компонент 4: «Отзывы и повторные визиты» (`ReviewsAndRetentionCard`)
* Разделено на две чистые секции:
  1. **Отзыв в 2GIS:** Тумблер + поле ссылки + время отправки (через 2 часа после визита).
  2. **Повторный визит:** Тумблер + срок напоминания («Напомнить записаться снова через: [ 30 дней ]»).

#### Компонент 5: «Тихие часы» (`QuietHoursCard`)
* Лаконичный виджет:
  * Включение/выключение ночного режима.
  * Время: `с [ 21:30 ] до [ 09:00 ]` (Часовой пояс: Алматы, UTC+5).
  * Компактная подпись: *«Сообщения, выпавшие на ночь, отправятся утром в 09:15»*.

---

### ЭКРАН 2: «Аналитика и конверсия»

#### Компонент 6: Верхние метрики (`FollowUpKpiCards`)
* 4 минималистичные карточки:
  1. **Отправлено касаний** (общее число за период).
  2. **Ответили на дожим** (число и процент отклика).
  3. **Доведено до записи** (сконвертированные клиенты).
  4. **Получено отзывов в 2GIS** (клиенты, перешедшие по ссылке).

#### Компонент 7: Воронка эффективности касаний (`FollowUpStepFunnel`)
* **Было:** `Step 1 (+2h)`, `Step 2 (+20h)`, неструктурированная строка цифр.
* **Станет:**
  * Четкая таблица/воронка конверсии:
    * **1-е касание (через 2 ч):** Отправлено | Ответов (%) | Записей (%)
    * **2-е касание (через 20 ч):** Отправлено | Ответов (%) | Записей (%)
    * **3-е касание (через 48 ч):** Отправлено | Ответов (%) | Записей (%)
  * Наглядный прогресс-бар показывает реальный % ответов (а не 100% заливку).

#### Компонент 8: Конверсия по каналам (`FollowUpChannelBreakdown`)
* WhatsApp, Instagram Direct, Telegram с понятными метриками отклика.

## 4. Словарь локализации (Замена терминов)

| Старый термин (в интерфейсе) | Новый рекомендуемый термин | Почему |
|---|---|---|
| `Lead Abandonment` | **Возврат замолчавших клиентов** | Понятно администраторам без знания английского |
| `Step 1 (+2h)` | **1-е касание (+2 ч)** | Убирает английское слово «Step» на графиках |
| `Step 2 (+20h)` | **2-е касание (+20 ч)** | Единый стиль нумерации касаний |
| `Step 3 (+48h)` | **3-е касание (+48 ч)** | Единый стиль нумерации касаний |
| `Win-Back` | **Повторный визит** | Избавляет от маркетингового сленга |
| `1-Click` | *(удалить бейдж)* | Лишний шум |
| `WhatsApp HSM-шаблон` | **Шаблон WhatsApp** | HSM — техническая аббревиатура Meta API |
| `Автоматизации активны` (баннер) | *(удалить)* | Статус уже есть в заголовке страницы |
| `Правило ≥ 48ч` | *(подсказка в тултипе)* | Не перегружает карточку лишним бейджем |
